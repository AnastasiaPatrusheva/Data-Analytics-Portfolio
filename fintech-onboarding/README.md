# 🏦 Анализ онбординга в финтех-приложении

Исследование влияния образовательного онбординга на поведение инвесторов, конверсию в повторные депозиты и структуру вложений в приложении для торговли финансовыми активами.

## 🎯 Бизнес-задача
Новые пользователи часто покупали высокорисковые активы без понимания механики рынка → несли убытки → уходили после первого депозита.  
**Гипотеза:** детальный онбординг с объяснением рисков повысит осознанность вложений, снизит отток после первой покупки и увеличит конверсию во второй депозит, не отпугнув осторожных пользователей на входе.

## 🔍 Что сделано
- Построила и сравнила воронки контрольной и тестовой групп
- Провела A/B-тест по конверсии во второй депозит (односторонний Z-тест)
- Применила бутстрап для оценки сдвигов 25-го, 50-го и 75-го перцентилей суммы депозитов
- Проанализировала влияние уровня риска первого актива на повторное вовлечение

## 📊 Данные и методы
- **Источники**: исторические данные (апрель–июнь 2025, ~41K пользователей) + результаты A/B-эксперимента (14 дней, ~9.4K пользователей)
- **Ключевые события**: регистрация, прохождение онбординга, первый/второй депозит, покупка актива с указанием уровня риска
- **Инструменты**: `Python`, `pandas`, `scipy`, `statsmodels`, `matplotlib`, `seaborn`, `Jupyter`
- **Подход**: проверка предпосылок тестов, расчёт доверительных интервалов через бутстрап, сегментный анализ

## 💡 Ключевые выводы
1. **Рост удержания**: конверсия из первого депозита во второй выросла на **+60,9%** (с 20,3% до 32,6%, p<0,001). Гипотеза роста подтверждена.
2. **Эффект «фильтра качества»**: онбординг не отпугнул аудиторию на входе (конверсия в первый депозит снизилась незначимо, −1,5 п.п.), но изменил структуру вложений:
   - 25-й перцентиль сумм депозитов снизился на **−47 ед.** (осторожные пользователи стали вкладывать меньше)
   - 75-й перцентиль вырос на **+20,5 ед.** (уверенные инвесторы увеличили чеки)
3. **Сильнее всего эффект проявился в группе высокого риска**: конверсия во второй депозит у покупателей risky-активов выросла на **+18,3 п.п.** (p<0,001). Обучение снизило импульсивный отток после убыточных сделок.
4. **Рекомендация**: внедрить обновлённый онбординг. Для масштабирования эффекта предложить адаптивную версию: упрощённую для новичков, расширенную — для опытных пользователей.
