# 🛒 Анализ маркетплейса: поиск точек роста и оптимизация маркетинга

Исследование поведения пользователей, эффективности каналов привлечения и монетизации маркетплейса на основе данных за 2024 год.

## 🎯 Бизнес-задача
Во второй половине 2024 года выручка маркетплейса начала стагнировать, несмотря на рост аудитории.  
**Задача**: выявить причины падения монетизации, оценить эффективность маркетинговых каналов и сформулировать рекомендации по восстановлению роста.

## 🔍 Что сделано
- Подготовила данные: объединила 5 таблиц (пользователи, события, заказы, товары, маркетинг), обработала JSON-поля, привела даты к единому формату
- Рассчитала ключевые метрики: MAU, DAU, Stickiness, CR, AOV, ARPU, ARPPU, CAC, LTV, ROI
- Провела когортный анализ: оценила окупаемость привлечения по месяцам регистрации
- Построила воронку покупок: выявил(а) основные точки оттока пользователей
- Проанализировала сегменты: каналы привлечения, устройства, регионы, категории товаров
- Провела статистическую проверку гипотез (Z-тест, t-тест) для оценки значимости различий

## 📊 Данные и методы
- **Источники**: 5 связанных таблиц (44 151 пользователь, 785 859 событий, 31 357 заказов, 88 записей маркетинговых затрат)
- **Инструменты**: `SQL` (агрегации, оконные функции, JSON-парсинг), `Python (pandas, matplotlib, seaborn, scipy, statsmodels)`, `Jupyter`
- **Подход**: 
  - Когортный анализ по месяцу регистрации
  - Расчёт юнит-экономики (CAC, LTV, ROI, Payback Period)
  - Сегментация и сравнение метрик между группами
  - Проверка статистической значимости различий

## 💡 Ключевые выводы
1. **Проблема — в качестве трафика, не в продукте**: во второй половине года доля пользователей из TikTok выросла с 15% до 62%, но их конверсия осталась на уровне 1,8–4,9% (ROI = 0,47x — убыток)
2. **Основная потеря — на этапе оформления заказа**: конверсия `checkout_start → checkout_complete` упала с 72,7% до 57,3%, особенно в дорогих категориях (мебель, техника, украшения)
3. **Высокоэффективные каналы недоиспользуются**: SEO (ROI = 69,5x) и Affiliate (ROI = 33,6x) получают <20% бюджета, несмотря на стабильную конверсию >35%
4. **Сегмент medium — точка роста**: 37% пользователей с конверсией 22,5% могут перейти в лояльный сегмент (regular, CR = 47,8%) при минимальных инвестициях в персонализацию
5. **Рекомендации**: 
   - Перераспределить 50–60% бюджета из TikTok в SEO и Affiliate
   - Оптимизировать этап checkout для категорий с AOV > 30 000 руб
   - Запустить email-кампанию для сегмента medium с бонусами за повторную покупку
